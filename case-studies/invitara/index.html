/ Project overview

Invitara is an invitation platform for weddings, engagements, birthdays, baby showers and other celebrations. Customers choose a design, personalise content and share a published guest link. The product combines animated storytelling with an editor, RSVP collection and an account dashboard.

The application uses Node.js, Express, SQLite and locally bundled animation libraries (GSAP, Motion, Anime.js and Three.js). The current collection contains independently designed invitations across many occasions, each built on a shared editor and content contract. Couple names and event details in the mockups are template placeholders, not commissioned client events. View project repository.

/ The customer journey

How the workflow works

A visitor previews a theme and creates a personalised draft before purchase. Verified checkout unlocks the purchased experience. The owner can publish a guest link, collect replies and review responses, with editing access governed by the selected event date and timezone.

  • Independently designed invitation compositions
  • Editable content, images, theme and section order
  • Guest replies and CSV export
  • Account-based saves and publishing

/ Design and development focus

Design and development focus

The server checks purchase status and expiry for save and publish actions. Stripe redirects alone do not unlock a purchase: the application verifies signed webhook events. Password hashing, account sessions and private owner access protect the editing and RSVP workflows.

  • Editable content, images, theme and section order
  • Guest replies and CSV export
  • Account-based saves and publishing
  • Stripe webhook purchase verification
  • Timezone-aware event expiry

/ Content and interface considerations

Implementation and scope

Developed application; not deployed to a public live URL. Drafts and previews work without payment credentials. Live checkout requires configured Stripe keys and webhook delivery. After the event, the editor becomes read-only and replies close while the published invitation remains available as a keepsake.

  • Guest replies and CSV export
  • Account-based saves and publishing
  • Stripe webhook purchase verification
  • Timezone-aware event expiry
