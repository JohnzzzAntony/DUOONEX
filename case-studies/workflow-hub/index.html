/ Project overview

WorkFlow Hub is built around a common operations loop: a request arrives by email, someone reads it, assigns it, replies and follows up until it is done. It covers website, online payments, web development, store support and back-office categories. Each task has a single owner, a due date and an activity history.

The application uses Next.js, TypeScript, Prisma and PostgreSQL with session-based sign-in for administrators and employees. An AI step extracts the subject, sender, summary, category and priority from a pasted email and drafts an editable reply. The device mockups were captured from a local build running demonstration data; names, branches and tasks are fictional.

/ The customer journey

How the workflow works

An administrator pastes an email, reviews the extracted details and the suggested reply, then creates the task and assigns an employee. The assignee is notified, updates status on the board and adds comments. The follow-up engine reminds owners before due dates and flags work that stalls.

  • Email-to-task intake with AI summary and reply draft
  • Kanban board and filterable list views
  • Single-owner assignment with comments and activity log
  • Automatic reminders, overdue flags and follow-up cadence

/ Design and development focus

Design and development focus

Scheduled jobs evaluate due dates, review reminders and renewal windows against configurable thresholds. Status changes write activity logs and notifications. Role checks separate administrator screens such as employees, settings and reports from the employee workspace.
