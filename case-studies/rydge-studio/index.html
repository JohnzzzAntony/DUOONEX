/ Project overview

Rydge Studio is a portfolio site for a creative studio with a home page, portfolio, project pages, services, about, blog and contact. Its visual language uses viewport-scaled typography, a strict black-and-white palette and motion such as marquees and text reveals.

Built with Next.js, TypeScript, Tailwind, Prisma and SQLite, with GSAP and Lenis for motion. The design language references a commercial Webflow template and was rebuilt with original placeholder imagery and copy; the engineering work is the CMS that makes every public section editable.

/ The customer journey

How the workflow works

Visitors scroll through the studio story, browse work and open project pages before getting in touch. The studio edits pages, sections, collections and media from the admin without touching templates.
